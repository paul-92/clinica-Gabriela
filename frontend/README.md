# Frontend Electron + React

Interface desktop moderna para o sistema da clinica, conectada ao backend FastAPI em `http://127.0.0.1:8000`.

## Instalar

```bash
npm install
```

## Executar em desenvolvimento

```bash
npm run dev
```

## Gerar build web

```bash
npm run build
```

## Telas principais

- Login
- Dashboard
- Pacientes
- Psicologos
- Agenda
- Prontuario
- Financeiro
- Relatorios
- Configuracoes

Quando a API nao estiver disponivel, a interface usa dados locais de demonstracao para permitir navegacao pelas telas.
