# Tema visual - Marilia Gabriela Gaspar

Tema criado com base na referencia visual do Instagram `mariliagaspar.psi`.

## Direcao visual

- Visual claro, acolhedor e delicado.
- Verde salvia como cor principal.
- Branco quente nos paineis.
- Cinza suave para textos secundarios.
- Azul escuro/cinza como cor de texto principal.
- Cantos arredondados discretos.
- Interface limpa, com poucos elementos decorativos.
